# 문파 시설 에셋 관리

- **배경:** `assets/backgrounds/sect-mountain.webp` (문파 영지의 지형만 고정)
- **건물:** `assets/buildings/{hall|yard|books|money|heal|dorm}/level-{1..9}.png`
- **에셋 규격:** PNG RGBA, 220 × 140 픽셀, 같은 투명 캔버스 위에 전체 건물과 부속물을 담습니다.
- **1단계:** 공터 에셋. **2~5단계:** 기초/중형 건물. **6~9단계:** 증축된 본관, 좌우 별채와 고유 깃발/부속물.
- **시설 고유 표현:** `books` 보라색 비급 깃발과 서고, `money` 황금색 금고·재화, `heal` 녹색 약탕·약초. `dorm`은 게임 표시명 **제자원**, `yard`는 **연무장**입니다.
- **좌표, 단계 이름 및 파일 경로:** `manifest.json`. 시설명·기능은 HTML `BLD`에도 정의되어 있으므로 실제 수치 변경 시 함께 관리합니다.
- **렌더링:** `assetForBuilding(id,level)`로 현재 단계 PNG만 표시합니다. 증축 시작 시 현재 단계 유지, 완공 시 다음 단계 교체.
- **화면 배치:** 문파 영지 지도는 **시설 탭 상단에만** 배치하고, 건물을 클릭하면 해당 건물의 상세 팝업을 표시합니다.
- **접근성:** 시설 건물은 `button`, 이미지 `alt=""`(버튼에 접근 가능한 이름 제공)로 처리합니다. 상세 팝업의 단계별 외형 비교는 토글로 개폐합니다.
